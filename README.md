# student-exam-score-prediction

A simple Machine Learning project that predicts students' exam scores using Linear Regression.

In this project, the model uses information such as study hours, sleep hours, attendance percentage, and previous scores to predict exam scores.

---

## Features

* Exam score prediction
* Data exploration and analysis
* Linear Regression model
* Model evaluation using regression metrics
* Actual vs. predicted score visualization
* Study hours vs. exam scores visualization

---

## Machine Learning Model

* Linear Regression
* Four input features
* Training and testing data split
* Model evaluation using MAE, RMSE, and R² Score

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

---

## Dataset

* Student Exam Scores Dataset
* Contains 200 student records
* Includes study hours, sleep hours, attendance percentage, previous scores, and exam scores
* Dataset source: [Student Exam Scores Dataset](https://github.com/Sainathmudigonda/Student-Result-Analysis)
